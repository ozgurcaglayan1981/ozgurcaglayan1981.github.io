Case studies

Problem, approach, result

De-Identification

Clinical De-Identification at Scale

Problem
Removing PHI from clinical text without sacrificing speed or accuracy.
Approach
Benchmarked rule-augmented NER, hybrid NER + zero-shot, and fully zero-shot pipelines across Databricks-AWS (CPU/GPU) and Google Colab.
Result
Cut CPU runtime from 9.4 hours to 26 minutes on 478K documents / 11.7M tokens; GPU acceleration brought the mid-tier pipeline to ~1 hour and the zero-shot pipeline to 6.5 minutes.

Healthcare Interoperability

From Doctor Notes to Structured Data

Problem
It's unclear how code creators, code mergers, and application layers fit together to make healthcare data usable.
Approach
Mapped the three-layer ecosystem: code creators (WHO, SNOMED International), code mergers (UMLS, OHDSI), and application layers (FHIR APIs, OMOP).
Result
A reference framework that helps healthcare NLP teams reason about terminology-integration decisions.
